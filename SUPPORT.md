# Support

## Where to ask

- Use [Discussions](https://github.com/joaocarlos2002/dark-knight/discussions)
  for questions, usage help, and design proposals.
- Use [Issues](https://github.com/joaocarlos2002/dark-knight/issues) for
  reproducible bugs and implementation work.
- Follow [SECURITY.md](SECURITY.md) for vulnerabilities.

Before asking, search existing issues and include the project version or
commit, operating system, Python version (when relevant), exact command,
expected behavior, actual behavior, and sanitized logs.
